# Stage 4：空间几何约束与候选摄影机位验收

日期：2026-11-14（Asia/Shanghai）。本阶段使用 Stage 2.1 原始视觉 JSON、Stage 3 地图库与真实轮廓进行离线搜索，没有调用视觉模型、收费 API 或读取照片 GPS、来源说明、人工机位答案，也未开发 Stage 5。

## 实际实现

新增 `geophotoloc/localization/`：`projection.py` 复用 Stage 1 AEQD 米制投影；`scoring.py` 复用 `bearing`、`signed_angle_difference`、`check_left_right`；`search.py` 管理有限网格、完整建筑/水域与 STRtree；`regions.py` 生成连通采样单元区域；`solver.py` 联合搜索不同身份组合、局部细化、排序并输出 JSON/GeoJSON。Stage 1 算法未修改，原 CandidatePose/LocalizationResult 接口保持兼容。

每个 Stage 3 RegionHypothesis 单独推理，不只取各对象 Top-1。拒绝跨区域、重复 OSM/Wikidata 身份及保守判定为同物体的分配。一个对象的不同名称不会生成另一个漏检对象。部分未匹配对象不参与求解；少于两个可靠图像横坐标时不生成摄影机点。

搜索范围由所选地标分布向外扩展，再与数据库记录的覆盖 bbox 相交。投影原点使用覆盖中心，仅定义坐标系，绝不直接作为结果；所有输出代表点均来自实际评估的网格点。可配置额外 search_bounds，不从测试答案获取边界。

## 几何约束、评分与参数

- 每条视线计算方位角及米制水平距离；重合/过近点拒绝。全局视场使用所有地标的最小圆周角跨度，检查能否处于同一正向视场。
- 可靠图像 x 建立全局顺序，结合 LEFT_OF/RIGHT_OF，每个无序对象对只计一次；互逆关系不会重复加分。ABOVE/BELOW 不作为地图南北或硬平面约束。
- 完整轮廓抽样顶点产生方位角不确定区间。视线近同向、接近反向或轮廓角区间重叠时可标记不可判定；其余明显顺序冲突为硬失败，不允许靠更多名称得分掩盖。
- 多个 FOV 与主点假设下，用简化水平针孔投影、圆周朝向平均和横坐标 RMSE 估计朝向。横向间隔只作软评分，保留 `camera_assumptions` 中的多个可行 FOV/主点/朝向，不把最佳参数当作测得焦距。
- 原始评分和过滤独立记录。完整建筑、水面和已选地标轮廓覆盖点被剔除，最多保留每组合 8 条过滤案例及原始约束分数。缺失/不完整地图不作为整片禁入依据；不处理复杂通行权限、桥面、楼层或船只站立条件。
- 启发式总分为 0.40×独立顺序满足比例 + 0.15×全局视场 + 0.20×横向投影质量 + 0.10×不同地标支持 + 0.10×Stage 3 身份分 + 0.05×完整轮廓比例。单地标不进入此排名。记录满足、冲突、不可判定数量和各分量；分数不是概率。

| 默认参数 | 数值 |
| --- | --- |
| 地标分布外扩半径 | 2200 m |
| 粗/细网格 | 180 / 60 m |
| 每身份组合/总评估点预算 | 4500 / 24000 |
| 身份组合上限 | 10 |
| 每组合细化连通区上限 | 6 |
| 细化层数 | 1（可设 0，仅执行粗搜索） |
| 每组合输出区域上限 | 8 |
| FOV 假设 | 60°,75°,90°,110°,130° |
| 水平主点假设 | 0.47,0.50,0.53 |
| 顺序角容差 / 最小图像 x 差 | 0.5° / 0.03 |
| 最小观察距离 | 5 m |
| 区域选择窗口 | 距最佳启发式分数 0.08 |

粗搜索后对多个高分连通块分别细化；未细化的高分粗单元继续保留。计算量/输出数超限明确标记 SEARCH_LIMITED，不把未搜索单元当作不可行。排序确定性；耗时不参与排序。同数据与配置的候选结果重复运行一致。

区域为已评分单元的并集，裁剪搜索范围并扣除完整建筑和水域，保留孔洞及连通形状；**单元内未逐像素验证，区域是采样近似，不保证每个内部点严格可行**。面积在局部米制投影计算，输出边界和代表点转回 WGS84。粗单元不会被虚构为微小圆形置信区。边界接触与覆盖裁剪分别记录。

## 状态、限制和 Stage 5 接口

INSUFFICIENT_EVIDENCE：少于两个可靠地标或没有确定顺序支持；NO_FEASIBLE_POSE：在已搜索范围/假设下无可行采样；SEARCH_LIMITED：计算或细化/输出预算截断，可能只有部分结果；AMBIGUOUS：存在可行区域但不能确认唯一位置/身份。SUCCESS 为模型保留值，当前策略不在缺少独立精度证据时自动发出。

未获取可信独立真实摄影机坐标，**没有米级误差评估**；网格间距、RMSE、面积均不等于定位精度或 95% 置信区。两地标顺序、未知 FOV、bbox 近似中心、地图裁剪、部分几何与通行数据不全均会保留较大不确定性。当前候选区域只是采样的几何可行性近似，未做遮挡可见性、三维高度/俯仰角或可靠焦距求解。

Stage 5 可调用 `PoseSolver(store, PoseSearchConfig(...)).solve(vision_result, map_matching_result)`，结果模型位于 `geophotoloc.models.pose`，也由 models/localization 包导出。`model_dump_json()` 给出完整状态、区域、地图实体、朝向、独立评分、过滤与预算依据；`.geojson` 是 FeatureCollection，含候选区域和实际搜索的最佳代表点。JSON/GeoJSON 足以供后续地图展示，**不应将结果标成已验证拍摄点**。当前阶段没有 Web UI。
