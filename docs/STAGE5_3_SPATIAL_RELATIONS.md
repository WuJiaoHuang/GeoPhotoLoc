# Stage 5.3：左右关系可靠性规则

这是预先固定的一轮保守对照。规则不接受参考机位、照片文件名、城市描述或GPS；位置参数只为原网格中的候选观察点。原Stage5.2函数、序列化及S0/S1/S2缓存保持不变，新入口为`build_reliable_spatial_refinement(vision, matching, pose, bounds, historical, evidence=None)`，返回独立版本`stage5.3`。

## 分类的实际条件

独立向量化函数`classify_relations(points, observations, candidates, geometries, relations, config, evidence=None)`返回逐点保留掩码及逐边分类、顺序和审计。边由原`order_constraints`提供：显式左右关系与可靠x顺序合并、互逆同义边去重；相反方向或显式关系与可靠x矛盾时整对UNKNOWN，不重复计权。

HARD必须同时满足：两个独立具体地图实体（复用OSM/Wikidata、近位置同名、等轮廓及same_object_groups检查）；两个可靠x且差大于原x_tolerance；模型身份不确定标志为false、地图identity_certain为true、primary名称相似度为1；完整有效建筑/塔的Polygon或MultiPolygon；图像边界框水平间隙超过同一x容差；另有带非空来源的独立`identity_confirmed`与`full_outline_visible`证据。这些证据默认false，模型自报置信度和精确名称不自动替代证据，也不把bbox当作完整可见轮廓证明。

逐候选点还需：观察点不在外环内部或边界（含庭院保守处理）；两个角区间均小于180°减容差；中心最小角差绝对值大于两半宽之和加容差；角差绝对值加两半宽之和小于180°减容差。角度统一北0°、顺时针，delta=(B−A+180)%360−180；已约定A为图像左侧，delta正为一致，负为冲突。无需假定相机朝北或图像左=地图西。两条界限的容差直接复用0.5°默认配置，未依据真实坐标改变。

SOFT：图像顺序有效、地图可用、几何非根本退化，但身份/完整可见性/地图完整性/图像框不满足HARD，或角区间接近、重叠、未充分分离。完整面比较全轮廓角区间而非建筑中心；有效但不完整面保留其不完整标记，仅为SOFT；只有点信息时采用代表点方向作SOFT诊断，不升级完整轮廓。确定一致1，几何不能区分0.5，冲突0。每候选点对SOFT边算术平均；没有SOFT为null。SOFT不影响保留、几何分数或最终排序；没有将分数解释为概率。

UNKNOWN：无地图候选、同一物理实体、方向矛盾、x不可靠或差太小、几何缺失/无效、观察点在建筑外环内部、角宽≥180°容差界、接近反向等不可可靠区分情形。UNKNOWN不产生排除或惩罚。有效图像中心顺序但框重叠时仅SOFT；中心本身模糊则UNKNOWN。

这意味着HARD不是整张图片的固定标签：同一边可以在不同点变成HARD满足、HARD冲突、SOFT或UNKNOWN。`hard_indeterminate`统计静态证据满足HARD而逐点几何不够的关系记录；这种记录已降级，并非实际施加了不确定硬筛。`hard_satisfied/conflicts`为逐点满足/冲突边数，评估另给至少一条对应边的点×身份数量。

## 与原S1的区别

原S1主要以可靠坐标、非不确定身份、精确主名称和完整轮廓作工程可信门控；没有独立身份/完整可见证据及图像框分离要求，也没有输出三级分级。原S1没有修改，本阶段保持原层逐字段相同。新路径只排除HARD冲突，SOFT与UNKNOWN保留，S1-R不承诺一定包含旧S1。

冻结真实数据没有独立可见性字段，也没有补人工答案。因此正式结果中HARD为0，S1-R=S0，明确未取得空间缩减。不能为使面积变小而推断证据齐全。合成场景通过独立构造证明HARD机制确能生效，但不是现实照片效果证明。

## 层构造与保持不变的部分

S1-R使用原E的相同距离合格粗/细/补充点、步长、身份组合、区域域；HARD保留点生成原采样单元再精确并集/求交，不使用凸包、buffer或真值补洞。S1-R⊆S0。S2-R只将原完整几何缓存应用到S1-R集合，原physical mask、鲁棒分数、FOV、score_window、750m分片、单身份8区域/全局12身份上限、Stage5.2质量优先选择全部不变。S2-R⊆S1-R。旧S1/S2为另一条并列链。

显示GeoJSON投影后再次求交避免直线弦细缝；面积在局部米制计算。仅复用原组件修复守卫，拒绝实质面积改变。每个候选的角投影按地标缓存，原完整几何评分完全复用，未重复视觉识别或在线检索。

## 测试与边界

覆盖清楚分离的一致/冲突、0°环绕与旋转、角区间重叠、大轮廓中心偏移、建筑内部、部分可见/塔冠证据缺失、互逆去重与矛盾、重复实体/显式同组、缺失/点/不完整地图几何、多个身份中一部分不确定、1e-8m扰动和角度容差带。合成集同时验证有HARD时收缩、证据降级时保留、SOFT均值/null语义、原输出未变及两组包含关系。

真实结果、失败案例、实际命令与全量pytest见[评估](STAGE5_3_EVALUATION.md)和[执行记录](evaluation/stage5_3/VALIDATION.md)。本阶段不进行身份模型训练、三维重建或连续优化。
