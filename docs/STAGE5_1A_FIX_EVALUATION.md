# Stage 5.1A-Fix 验收报告

日期：2026-11-16。本次只修复搜索分配、部分水平可见模型和两阶段遮挡。视觉 API 请求 0 次，在线地图请求 0 次，无新增依赖；沿用现有本地 OSM 数据和四张照片的原始视觉/实体候选 JSON。Stage 2/3 核心代码及旧 Stage 4、Stage 5、Stage 5.1A 评估文件均未改动。

## 根因与修复

原自适应模式只扩大矩形，按 y/x 顺序扫描，距离不合格点同样消耗预算，较早身份组合也可能抢占总额度。原完整轮廓必须进入 FOV 的约束把“识别到建筑”错误等同于“整栋建筑全部入画”。原射线检测在大量几何可行网格点上逐目标执行，昂贵工作被反复执行。

新增 `sampling.py`、`partial.py`、`fixed.py`，在现有几何工具和模型之上增加独立修复路径。`PoseSolver` 默认与 `BaselinePoseSolver` 保留原 Stage 4 行为；`EnhancedPoseSolver` 默认进入修复路径，显式 `viewpoint_fix=False` 可回放 Stage 5.1A；`FixedPoseSolver` 明确启用修复路径。旧求解函数和完整轮廓算法保留，未大规模重构页面。

## 距离可行域与分层预算

局部米制域 `S = intersection_i buffer(G_i, R)`，完整有效建筑几何优先，没有完整有效轮廓退化为实体代表点。R=5000 m，上限 10000 m。buffer 使用 32 个四分之一圆分段，并用 `R/cos(pi/(4*32))` 外包修正，避免内接多边形误删边界真实可行点；所有样点仍以真实最短距离 `d(P,G_i)<=R` 精确过滤。目标间距大于 2R 或交集为空时立即结束，不扫描外扩矩形。最小观察距离仍为 5 m。

总预算仍为 24000，单身份最多 4500。先向所有有效身份组合公平预分配，再在每个身份的连通分量内按面积分配：预算允许时每分量至少一次机会，剩余额度按面积/最大余数分配。动态粗间距 `clip(sqrt(A/N),180,600)` m，细间距 60 m，初始比例为 60%/30%/10%。粗/细额度用不完时转给补充层，并在 budget_allocation 中记录。跨身份采用预分配，未实现剩余额度的跨身份二次回收；全局未使用额度明确输出。

每个分量先建立均匀内部候选池；窄长分量漏掉格点时用等宽条带与多边形交集的内部代表点补足机会。以渐进 maximin 次序空间分散采样，分量间轮转，坐标哈希仅用于确定性平局处理，输入遍历顺序不能改变样点排序。补充层采用 1/4、3/4 的错开格点，避免再次访问已耗尽的初始格点。没有使用参考机位决定采样、范围或先后顺序。

每身份输出预算、每分量 coarse/fine/supplemental 点数、实际使用数、planned_work、预算使用率和 sampling_completion_ratio。后者仅是已完成的策略内计划工作比例，不是连续位置穷尽比例。unsearched_area_m2 为 S 减去实际评估样点单元并集的面积；sampled_geometry 也仅表示已评估样点的单元覆盖，不能把整个单元当作实际逐点检查或可站立证明。预算、细化/输出上限或仍有未覆盖面积时保留 SEARCH_LIMITED。

## 部分可见建筑模型

复用原外环/多多边形/圆周最大空隙算法得到建筑角区间 I_G(P)。相机区间为 I_C(H,F)，计算 `I_V=I_G∩I_C` 和 `r_v=|I_V|/|I_G|`；“可见”只指水平视场交集，不代表三维无遮挡。完全不相交拒绝，部分相交可接受，默认最低比例 0.05。极小角宽使用绝对角阈值 0.02°（不超过自身角宽）避免数值误判；点或无效/缺失轮廓不生成比例，降级为 UNKNOWN/POINT_APPROXIMATION。阈值均为工程假设，未经统计校准。

图像 x±0.06 对应一个可能视线区间；对每组预定义 FOV/主点，将该区间与建筑可入画方向共同转换为允许朝向圆弧并求交。重投影残差是图像观测到可见角投影区间的距离，不强迫 bbox 中心对应完整建筑中心。可靠完整轮廓确实相反的左右顺序为硬冲突；重叠为 INDETERMINATE，点位置的近似顺序只作软证据。互逆关系和 x 顺序按对象对去重。

没有根据真实照片或参考坐标调整 0.06 容差、0.05 比例、R 或原 FOV 列表。区域和相机假设仍可能多解，未宣称唯一机位。

## 两阶段评分与区域接口

第一阶段完成距离、已知建筑/水域、顺序、共同部分视场和图像投影检查，不发射遮挡射线。C/D 使用 `S1=0.80*base+0.15*footprint+0.05*0.5`；A/B 保持原几何评分。

第一阶段结束后，按身份组合分配复核额度，从每个输出空间分量选择最佳样点及可行样点 medoid；默认每身份最多 20 个、全局最多 100 个，每目标最多 12 条射线。复用 SearchContext、投影缓存和 STRtree；可见性结果采用最多 2048 项的上下文 LRU。第二阶段 `S2=0.80*base+0.15*footprint+0.05*visibility`。保存 stage1_score、stage2_score、visibility_reviewed 和逐目标状态/比例/覆盖率；未复核不标 CLEAR。地图未知时质量为中性 0.5，r=1 也不单独硬拒绝。

按身份、几何连通区域使用各自分数窗口，再保留局部最高分与空间多样性；输出上限仍可能丢弃部分可行区域，明确标记。每区域新增 best_scored_point 和 region_medoid，medoid 是可行样点中欧氏距离和最小的实际点。best_location 保留兼容别名；原 JSON/GeoJSON 字段未删除，GeoJSON 新增 medoid 点。两者都只是候选，不是真实拍摄点。
