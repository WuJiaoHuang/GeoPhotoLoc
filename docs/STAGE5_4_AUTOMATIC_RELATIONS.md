# Stage 5.4 自动关系评分与 F 排序

正常动态输入只有一张照片。默认LocalizationPipeline使用F；现有服务端地图数据库和固定配置可复用，不接受城市/GPS/身份确认/相机真值。显式旧search_config或automatic_relations=False保留历史路线。Streamlit在线默认选中Stage5.4，旧定位和Stage5.2仍可选择。离线按版本读取冻结结果，不因页面刷新请求模型。

## 预先固定的图像权重

关系统一为(left,right)，由现有显式LEFT_OF/RIGHT_OF及可靠x顺序生成，互逆等价边去重。显式与可靠x矛盾或同一对存在双向冲突时，两方向权重均0，不以一条矛盾边硬排除。任一坐标不可靠或xb-xa≤既有x_tolerance时w=0。同一物理实体（identity key、原判同/等价轮廓、equivalent IDs、显式同对象组）w=0。

令 s=max(0,xb−xa−x_tolerance)。缺少任一bbox时w=0.5s，最大严格低于0.5。两个bbox都有时，W=max(两框水平宽度,x_tolerance)，g=max(0,b.x_min−a.x_max−x_tolerance)，w=(g+0.5s)/(W+g+0.5s)，裁剪到[0,1]。同样中心顺序下，分离框的正g提高权重；相交框g=0且大W降低权重。只有连续权重，无新增按照片调节的几何阈值。视觉权重不乘地图名称分或模型置信度。

## 身份与逐点几何证据

逐身份保留实体ID、名称相似度、类别一致性、模型身份不确定标志、原地图匹配分和轮廓完整性；这些字段不能解释为概率，也不据此固定唯一身份。沿用原联合身份组合及预算，候选名称不补齐漏检对象。

完整有效面轮廓复用现有角投影数组，按地标缓存。北0°、顺时针；中心最小角差δ=(B−A+180)%360−180。以两半宽和h及既有angular_tolerance_deg判断：两角宽均<180°−tol、观察点不在任一外环/边界、abs(δ)>h+tol、abs(δ)+h<180°−tol，才有可区分顺序。δ>0一致c=1，δ<0冲突c=0。重叠/接近反向/宽角区间/建筑内部/缺完整轮廓时c=0.5。未假定相机朝北或图像左等于地图西；未确定遮挡、FOV及三维可见性。代表点顺序从不当作完整轮廓结论。

每点 relation_score=sum(wc)/sum(w)，只纳入w>0的边；无有效视觉关系则null。缺地图/轮廓的图像关系保持中性0.5，不能伪造确定方向。记录每边视觉权重、身份组合、逐点c、wc、determined标志、冲突数和不可判定原因。未知几何并不等于可靠一致；该均值不是概率。

## 有界 F 区域保留与排序

F仅在原E最后的区域保留处启用，粗/细/补充搜索、身份、原鲁棒评分、物理站立、水域、5km距离、FOV和原score_window均不变。保留原750m分片、每身份8区域及最多12身份等原配置预算。

原E生成采样单元、精确交并、同E质量连接合并的机制保持。合并是否允许和坐标锚点沿用原E质量/稳定坐标，不让新增关系分改变可供选择的基础模式。合并后由F质量选已有代表样点；没有凸包、额外buffer或新搜索点。最后优先级：

1. 原综合分及geometry分分别round到六位小数的质量档。
2. 自动关系分round六位小数；null只在排序键中为中性0.5，输出仍null。
3. 原独立可靠地标数量。
4. 原档内最大空间分散与毫米稳定坐标；全局沿用身份ID/坐标稳定次序。

完全没有可用关系时，区域选择直接调用原E默认质量函数；全局中性关系项不会改变E顺序。混合缺失证据时null为中性，不把缺失当作1。任何显著较低几何质量都不能因高关系分反超。没有关系硬筛；未选模式只是原输出预算下的启发式保留，完整截断审计保留质量档、关系分、界与丢弃原因。

## A0/A1/A2 与复现

A0直接复用冻结S0；在线从同样已访问距离合格点生成原采样单元。A1与A0集合完全相同，仅添加全体点×身份的关系分布，不宣称面积缩减或物理可行性。A2的几何和顺序直接取F实际输出，不是另一套S2求解或按真值独立选择的区域。A1的范围很宽是允许结果；A2是有界启发式优选，可能遗漏正确位置。

真实正式比较使用相同照片/视觉JSON/地图快照；F重新运行同样求解并以完整trace SHA严格核验E/F采样坐标、phase、原分数/分项和Feasible一致。规则/源码先冻结，推理完成全部结果SHA冻结后，独立评估脚本才读取Camera location。旧development/holdout已查看，只作诊断回归，不宣称泛化。没有新VLM/Overpass请求。

接口：`automatic_relation_scores(points, observations, candidates, geometries, relations, config)`；`Stage54PoseSolver(store, config).solve(vision, matching)`；`LocalizationPipeline(db).run(photo)`。已有旧代码/输出可用历史版本/显式配置复现。全指标、失败与命令见[评估](STAGE5_4_EVALUATION.md)。
