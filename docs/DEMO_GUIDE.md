# GeoPhotoLoc 导师演示流程

1. 在项目根目录执行 `uv sync --locked`，然后 `uv run streamlit run src/geophotoloc/app/main.py`。
2. 默认离线模式选择北京 CBD。说明“离线复现实验结果，非本次实时模型推理”，不消耗模型请求、无需地图数据库。
3. 左侧展示原图、地标框、身份候选；右侧地图显示中国尊/央视总部及两个候选区域。用图层和聚焦控件查看区域、朝向、可选视线。
4. 展开地标匹配及几何证据，展示启发式分、满足/冲突/不可判定数量、区域面积及边界限制。不能把一个代表点称为确定拍摄点。
5. 切换广州：展示东西塔错误 Top-1 与其他身份组合、8 个区域和 SEARCH_LIMITED。说明并未用正确答案强制消歧。
6. 切换东方明珠：展示正确地标及 INSUFFICIENT_EVIDENCE，没有虚构摄影机点。
7. 展开独立机位评估：北京来源机位位于原覆盖外；北外滩未被最终多边形包含，具体距离仅是该样本相对于来源自报坐标的误差；东方明珠不计算空候选距离。不能据此宣称通用米级精度。
8. 下载完整 JSON、GeoJSON 和标注图片。离线地图没有网络底图，但区域、地标、平移、缩放和属性可使用本地打包资源。
9. 在线演示前准备本地 `.env`，执行 `uv run python -m geophotoloc.cli demo-setup`。上传图片并点击“开始定位”，等待真实视觉 → 地图 → 几何流程；改变页面控件不会自动调用模型。重复同图缓存与实时请求状态会区分。

新增北外滩真实联调资料及独立来源见 `docs/evaluation/stage5/`，`north_bund_map.html` 可单独离线打开。三张既有案例原始结果没有为展示而修改。
