# Stage 5.1A 实验验收

日期：2026-11-14。复用现有四张照片保存的原始视觉结果和地图匹配结果，视觉 API 请求 **0 次**，地图在线请求 **0 次**。使用已有 SQLite 的 21,178 个有效 OSM 要素及导入记录。Stage 2、Stage 3 核心策略及 Web 页面均未修改，历史 Stage 4、Stage 5 实验文件保留原字节。

## 边界根因与实现

旧求解器将地标代表点外扩 2200 m 的矩形与 OSM 导入 bbox 相交，并把覆盖外观察点当作硬过滤条件。北京来源自报相机经度 116.435464，而已导入北京 bbox 西边界为 116.440：物体在地图内不意味着相机也在该 bbox 内。默认 `PoseSolver` 保留这一 Baseline 行为；新增 `BaselinePoseSolver` 和 `EnhancedPoseSolver` 及独立开关。

增强搜索集合为 `S = intersection_i {P: d(P,G_i) <= R}`，其中完整 Polygon/MultiPolygon 使用到几何的最短米制距离，缺失完整轮廓才退化为代表点。R 默认 5000 m，上限 10000 m，最小距离 5 m。先由全部目标几何外扩矩形生成网格，128 点有界批次向量化距离过滤，再计算角区间和遮挡。搜索矩形不与地图覆盖相交；用户显式配置的 search_bounds 仍可生效。本次实验没有设置此项。

粗网格 250 m、细网格 60 m；保留每假设 4500 点、总 24000 点、最多 10 个身份假设、6 个细化连通分量和每假设 8 个输出分量的预算。计数包括距离过滤的网格点，预算耗尽标记 SEARCH_LIMITED，不把未搜索点宣称为不可行。粗网格高分连通分量全部保留到区域构造，多个分量分别细化。

## 完整轮廓与二维可见性

`footprints.py` 使用所有外环顶点，不再抽样代表轮廓。北向顺时针方位角排序后取最大圆周空隙的补集，得到跨 0° 的最短角区间。Polygon 内部/边界禁止站立；孔洞内观察者的外环环绕视角记为 360° 并通过共同视场约束拒绝；无效几何明确退化，MultiPolygon 汇总所有外环。缺失完整轮廓标记 POINT_DOWNGRADE，不把点顺序冒充轮廓证据。

所有目标使用同一最短圆周覆盖的中心方向展开；区间分离判定 SATISFIED/CONFLICT，重叠、反向或展开歧义判定 INDETERMINATE。全轮廓还需落在同一组 FOV/主点/朝向假设内，可靠的互逆左右关系与图像坐标顺序按无序对象对去重。地图经纬方向不直接解释为图像左右。

`visibility.py` 从最近边界、角区间两端和其他边界点生成最多 12 条视线，方向近重合去重，并截断到目标第一次边界交点。复用 SearchContext 的 STRtree，使用索引内精确 intersects 谓词排除包围盒假阳性，按实体 ID 缓存物理重复表示判断；排除目标自身/同一物理实体。不会按每个点加载数据库或遍历所有建筑做相交。

二维阻挡比例 `r = blocked_rays/valid_rays`；完整覆盖时 r=0 为 CLEAR，r>0 为 POTENTIALLY_OCCLUDED，r=1 另记 fully_blocked_2d。没有高度、相机高度和俯仰，全部二维受阻也不单独硬剔除。任意视线走廊未被导入覆盖完整包含，则状态 UNKNOWN，同时保留已观察阻挡比例。

COMPLETE 仅表示成功的含完整建筑几何查询、来源时间/hash、bbox、实体数量等导入记录与当前数据库相符，且所需几何落在这一覆盖内；不是现实地图无遗漏的保证。PARTIAL 表示部分相交，UNKNOWN 表示范围外或导入证据不足。未知区域保留候选，但不能解释为安全、可通行或没有遮挡。真实库另发现 5 个仅节点建筑及 1 个不完整建筑轮廓：已加入不完整范围的空间索引；视线/候选触及已知不完整几何外包范围时降级，无法界定轮廓的仅节点建筑保守降级所在导入覆盖。视线状态因此可能是 UNKNOWN，即使没有查到阻挡也不标 CLEAR。区域/代表点的 map_coverage_status 作用于其空间几何，完整视线覆盖另见 complete_ray_fraction；两者均不是现实地图无遗漏的承诺。

## 评分

先检查硬约束：与目标不重合/不在其轮廓内、完整几何最短距离、全局共同视场、可靠明确左右不冲突、已知建筑内部/水域过滤。之后增强分数为：

`S = 0.80 * base_score + 0.15 * footprint_consistency + 0.05 * visibility_quality`。

base 使用原 Stage 4 组件和权重，在轮廓模式下由精确区间替换旧近似顺序判断，并保留可行全轮廓相机假设。`footprint_consistency=(satisfied+0.5*indeterminate)/(satisfied+indeterminate)`，无独立证据取 0.5；`visibility_quality=1-0.5*r`，未启用/证据不足取 0.5。未知可见性不高于已知完全二维阻挡，避免缺失地图自动获益。另输出 footprint/visibility 有效证据覆盖率、geometry_completeness、每目标角区间和遮挡明细。Extent-only 使用原评分，Footprint-only 的未启用 visibility 分量固定 0.5；权重不依样本调整。

所有分数是预定义启发式分数，不是概率，也不是位置误差或 95% 置信区间。

## 消融协议与数据隔离

A=三个开关全关，B=仅 adaptive_extent，C=仅 footprint_constraints，D=全开。四组共用 250/60 m 网格及其余所有参数，只有三个开关不同；A 与历史 Stage 4 默认 180 m 网格的数值不可直接混为一组。本阶段还用 Stage 5 提交 `451ed058` 的原始 solver.py 独立执行同一离线测试场景，捕获默认输出精确几何/坐标/分数摘要，回归检查 SHA-256 及 2352/2140 搜索/可行点，验证旧默认行为复现。

`evaluate_stage5_1a.py` 只读原视觉/匹配 JSON，通过参数对象调用 solve；每组保存相同输入 SHA-256。北外滩直接复用 Stage 5 pipeline 中的 vision、matching 两段，不使用旧定位结果。文件名仅用于脚本选择输入，不传入求解器。全部 16 个独立求解完成后，`evaluate_stage5_1a_truth.py` 才读取来源自报相机位置，计算区域包含、区域最近距离和代表点距离。后评估另记录真值处的几何最短距离和二维遮挡，不回写候选或用于调参。广州只有桥级来源描述，不计算虚构的米级误差。

OSM 数据署名为 © OpenStreetMap contributors / ODbL，来源与许可证见 [Stage 3 数据署名](evaluation/stage3/ATTRIBUTION.md)。

完整 JSON（内嵌 GeoJSON）和四个 summary 位于 `docs/evaluation/stage5_1a/`。搜索面积统计为各身份假设网格搜索域面积之和（A/C 为与地图交集，B/D 为外扩矩形），重叠可重复计入，并非连续 S 的解析面积；可行点必须通过精确距离过滤。候选总面积按身份区域求和，重叠可能重复计入。顺序冲突计数按实际执行的独立“点–对象对”检查累加，硬过滤提前退出的点不进入后续检查。区域面积是粗/细采样单元并集，边缘和障碍物孔洞存在离散误差，不保证整个单元均通过硬约束。潜在遮挡计数为被实际评估的“点–目标”对，包含覆盖不足 UNKNOWN 中观察到的阻挡，不是唯一建筑数量。

### 北京与北外滩的实际对比

北京：A 搜索域 10.462 km²，B/D 为 107.049 km²，来源相机进入新搜索域，后评估确认到各目标几何的距离也均在 5–5000 m 内；不再被原 OSM bbox 截断。最近区域距离 A=624.10 m、B=251.42 m、C=515.46 m、D=224.67 m。改善主要来自范围扩展；B→D 的本样本额外差值为 26.75 m，不能解释为一般精度收益。四组都没有覆盖来源相机点。Top-1 距离 A/C=2559.02 m、B/D=3771.88 m，反而增大；D 区域面积达到 24.463 km²，范围修复没有解决唯一定位。

北外滩：A/B 最近区域距离均为 19.08 m、Top-1 距离均为 60.14 m；C/D 分别变为 64.09 m 和 385.41 m，发生退化。A/B/C/D 区域数为 6/11/7/14，总面积为 2.612/9.244/2.178/8.576 km²。单加轮廓 C 相对 A 面积缩小，但误差更大；扩范围 B 相对 A 只增加歧义，没有改进最近距离；D 相对 B 面积有所收缩，仍不覆盖来源点，不能将“更小”当作“更准确”。所有身份组合原样保留，包括其法院等候选，未按来源机位修正匹配。

后评估的已知建筑/水域站立过滤在北京、北外滩和东方明珠来源点均为空（postsolve_standing.json）；因此这些点没有落入输出区域不能直接归因于上述站立过滤。有限网格/细化与输出预算、轮廓全局视场约束、图像中心和身份误差仍是限制；本次没有独立校准来确定各因素的误差占比。

## 失败、限制与连续优化接口

有限预算、离散单元和粗网格仍可能漏掉狭窄可行走廊；扩大范围会增加候选面积，并可能耗尽预算。地图覆盖外候选缺少站立和遮挡验证，必须保留 UNKNOWN。只有二维建筑轮廓不能证明真实三维可见性，OSM 缺失与高度未知均不能通过评分掩盖。低残差、较高启发式分数和真值落入宽大区域都不等于精确定位成功。

广州沿用原 MapMatcher 的东西塔身份歧义与全部可用组合，没有读取人工正确身份来修复匹配；视觉漏检、中心/边框误差、轮廓地理配准误差继续存在。东方明珠近景单地标继续证据不足，无区域也无虚构定位距离。四张照片只能说明本次样本，不能宣称普遍准确率。

下一步可直接复用 `adaptive_search_extent` / `within_observation_distance`、`angular_footprint` / `local_interval` / `footprint_order`、`potential_visibility`、`evaluate_enhanced_pose`；输入均为局部米制几何与相同身份组合，输出含退化状态、分项证据与硬可行性。连续优化可消费区域及 best_location 作为初始化，保留多身份/多区域与 UNKNOWN，不把区域代表点当作真值。本次未实现连续优化或扩大其他阶段范围。
