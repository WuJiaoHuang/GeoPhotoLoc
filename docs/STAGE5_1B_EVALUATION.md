## 身份候选与 Beam

每个图像 ID 只使用其原 Stage 3 候选，最多 3 个，加一个真正未匹配的 None/UNKNOWN，不是新 OSM 实体。优先级依据原名称分数、类别一致性、几何完整性；不完整几何不硬删。Beam width=24，进入几何求解的联合分配最多 12。每层保留词义高分分配及不同 UNKNOWN 掩码，避免所有未匹配选择被词义排序挤掉。候选生成不读照片文件名、机位或正确身份。

检查共同区域、地理一致性和物理实体唯一性；复用 Wikidata/原去重规则，并识别相同完整轮廓的不同 OSM 表示。`same_object_groups` 仅允许调用方依据明确视觉标注声明同一对象；即使如此，重复物理实体不增加可靠独立地标计数。原 `region_hypotheses` 未删改，保存在新结果 diagnostics 供对照。UNKNOWN、Beam 截断和原始池均显式输出。

## 硬约束与鲁棒软评分

硬拒绝仅来自已知建筑/水域不可站立、目标重合/最小距离、最大观察距离、物理实体违规重复、可靠独立地标不足。视场、图像顺序、bbox 中心及名称不是硬事实；明显视觉冲突仍可保留为低分候选。

对每组有限相机假设计算 `alpha_i = theta + atan(2*(x_i-c)*tan(F/2))`，误差为观测方向到建筑角区间的最小圆周距离。复用完整轮廓及部分视场交集；点状/缺失轮廓采用代表方向加默认 ±2° 工程不确定性，并标 POINT_DOWNGRADE，不能当精确建筑轮廓。误差证据中保存 raw_error_deg、normalized_error、tolerance_deg、huber_loss 和允许角宽。新鲁棒路径的标量 projection_rmse 是角度 RMS，旧路径的该字段仍是原归一化图像残差；比较时使用明确带单位的新证据字段，不混用二者。

角度容差由同一 FOV 下 x±0.06 的视线角宽推导，最小尺度 0.05°，再归一化残差 z。Huber 默认 delta=1：小误差 0.5*z²，大误差 delta*(abs(z)-0.5*delta)。投影分采用可靠性加权平均 Huber 损失的 exp(-loss)，再按已匹配观测覆盖率调整；缺失投影证据只取保守 0.25。坐标标记不可靠的证据权重为 0.35，均为未校准工程量，不是概率。

联合分严格为 `0.40*projection + 0.20*order + 0.25*identity + 0.15*geometry`，各项在 [0,1]。身份沿用 Stage 3 分数，UNKNOWN 身份不发奖励，几何质量缺失降低。内部 LEFT/RIGHT 与可靠图像 x 矛盾时权重降至 0.25 并记录原因；互逆边去重。地图左右冲突只降顺序分；重叠/未知取中性证据，绝不自动计为满足。

相机假设为原 FOV/主点列表及观测对齐的中心/边界/均值方向的有限代数种子，没有连续优化或内参标定。权重、容差、R、Beam 和预算均在后评估前固定。

### OUTLIER 与可辨识性

最多剔除 1 个已分配观测；必须同时比较保留/排除后的拟合，归一化残差 >2.5、平均损失改善至少 1、惩罚后的联合分更高，且至少剩 2 个可靠独立地标才允许。排除在身份分中另减 0.08，并降低有效支持/几何覆盖；不是无条件按最大残差删除。输出每个比较、被排除 ID 和理由。UNKNOWN 是身份假设，不伪装为已验证正确或 OUTLIER。

0–1 个独立可靠地标返回 INSUFFICIENT_EVIDENCE；2 个只允许歧义区域，分数附 AMBIGUOUS_TWO_LANDMARKS；多地标及退化分布仍保留歧义，不返回唯一成功点。预算耗尽时总状态可为 SEARCH_LIMITED，同时 identifiability 明确为 AMBIGUOUS。

## 双层区域与面积

Feasible 保留通过物理硬限制的已采样单元包络，不经过视觉分数窗口：LOW_UNRANKED，含义是“在地图和距离假设下尚不能排除”，不是高置信位置或已确认可通行区域。已知障碍和目标最小距离区被扣除；不存在为了命中机位而增加的统一 buffer。buffer 仍仅用于原 5000 m 观察距离域和 5 m 排除距离。
